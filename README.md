# 红果助手 (Hongguo Ad Swiper)

**在红果免费短剧等信息流 App 里，自动识别广告/推广页并上滑跳过。**

免 root · 不联网 · 免插件 · 装上即用一个 App 搞定全部。

## 这是什么

刷红果短剧时，信息流里隔三差五插进来一页广告/直播推广，得手动上滑划走。**红果助手**在后台帮你划：

| 识别方式 | 抓什么 |
|---|---|
| 商业词组合 | 「进入直播间」「优选服务」单词即滑；「预约/咨询/查看详情」等同屏两词、或一词+严格「广告」标签 |
| 上滑提示 | 广告页的「上滑继续观看短剧」提示（有读秒先等倒计时走完） |
| 「上滑」像素模板 | 广告提示是图片渲染读不到文字时，用 ZNCC 模板匹配 + 文字极性校验兜底 |
| 直播红标 | 左下角「直播中」饱和红标签（安静直播也能识别） |
| 动静反差 | 全屏推广视频（中部大动）+ 底部静止横幅 |
| 倍速守卫 | 检测到倍速面板/倍速快进字样时暂停一切滑动，防止误触 |

命中时屏幕右上角闪一个白色小圆点（2.5 秒消失），表示"刚才识别划走了一个"。

> **和 GKD / AutoX.js 方案的区别**：老办法要装 GKD（或 AutoX.js）+ 导订阅规则/配模板图，两个 App 来回切。本项目把**配对、检测、滑动全部内置**，装这一个 App 就能用——两个 App 变一个 App。

## 工作原理

```
┌─────────────────────── 红果助手 App ───────────────────────┐
│                                                            │
│  SkipService (AccessibilityService)                        │
│  ├── 自适应自检循环: 息屏 1.5s / 目标App前台 250ms / 后台 1s   │
│  ├── 前台判定: 聚焦窗口 → 活动窗口 → 30s 事件流兜底             │
│  ├── 文字路径: 无障碍节点遍历 → 倍速守卫/商业词/上滑提示词        │
│  ├── 像素路径: takeScreenshot API → ZNCC 模板匹配            │
│  │            + 直播红标 + 动静反差                          │
│  ├── 看门狗: 无障碍通道僵死 → 自动 关→开 重绑自愈               │
│  └── 命中 → 白点角标 → 上滑                                  │
│                                                            │
│  AdbShell: 内嵌 ADB 客户端                                   │
│  ├── mDNS 自动发现无线调试端口(每次开机变, 无需手填)              │
│  ├── SPAKE2+ 配对(6 位配对码, 一次配对终身有效)                 │
│  └── shell: input swipe  ← 滑动主通道                        │
│                                                            │
│  Shizuku(备用通道) / dispatchGesture(兜底)                   │
└────────────────────────────────────────────────────────────┘
                        ↓ ADB over Wi-Fi (localhost)
                 本机无线调试 → shell 上滑
```

**为什么靠无线调试（ADB）？** 红果的广告/推广页会拦截无障碍手势，所以滑动走 `input swipe`（shell 权限）。无线调试是系统自带能力，配对一次终身有效，不费流量、几乎不费电。

## 技术栈

| 模块 | 技术 |
|---|---|
| 语言 | Java 17 + Kotlin 混合 |
| 最低版本 | minSdk 26，targetSdk 34；**完整检测需要 Android 11+（截图 API 限制）** |
| 检测核心 | AccessibilityService 自检循环 + 无障碍节点树文字分析 |
| 截图识别 | `AccessibilityService.takeScreenshot`（API 30+）+ 自实现 ZNCC 归一化互相关模板匹配、亮度网格静止度/对比度分析 |
| 滑动通道 | 内嵌 ADB 客户端（协议/配对代码源自 [Shizuku](https://github.com/RikkaApps/Shizuku)，Apache-2.0）→ `input swipe`；Shizuku API 备用；`dispatchGesture` 兜底 |
| 无线调试配对 | ADB TLS + SPAKE2+（BouncyCastle），mDNS（NSD）自动发现配对/连接端口 |
| 通道自愈 | 看门狗检测无障碍僵死连接，经 ADB 自动 关→开 重绑 |
| 构建 | Gradle 8.5 + Android Gradle Plugin 8.2.2，无需 Android Studio |

## 使用教程（3 步，一次性）

App 首页有同样的步骤引导，跟着做即可，全部变 ✅ 就能用：

### ① 无线调试配对（拿 ADB 权限，一次配对终身有效）

> 前置：手机必须先连上 Wi-Fi。没连 Wi-Fi 时开发者选项里的无线调试会提示「请连接到 WLAN 网络」。

1. **手机连上 Wi-Fi**
2. **打开无线调试**：设置 → 开发者选项（没有的话进「关于手机」连点「软件版本号」7 次开启）→ **无线调试** → 开启
3. **点「使用配对码配对设备」**，弹出 6 位配对码
4. **回到红果助手**，把 6 位码填进去 → 点「配对」
5. 看到「🟢 ADB 通道已连接」即可（端口自动发现，不用填）

> - 配对一次终身有效：**之后只要无线调试开关开着，同一 Wi-Fi 下会自动重连，不用再输验证码**。
> - 手机重启后端口会变，App 会用 mDNS 自动重新发现，同样不用管。
> - 无线调试开关别关（保持开启，费电极少）。被系统关掉了会发通知，点通知重连。

### ② 开启无障碍

回到红果助手点「一键开启」，或 设置 → 无障碍 → 红果助手 → 允许。
如果列表里找不到或开了没反应，搜索一下你机型的「无障碍服务授权教程」按着做即可。

### ③ 防杀后台（vivo / OPPO / 小米等必做）

国产系统管后台严，不做会被系统杀掉无障碍：

- App 高级设置里**一键加入电池白名单**
- 系统设置里允许红果助手「自启动」；vivo 还要开「后台高耗电」，OPPO/一加开「完全后台行为」，小米把省电策略设为「无限制」
- 最近任务里下拉锁住红果助手卡片

**全部 ✅ 后**：打开红果短剧正常刷剧，广告/推广页会被自动划走。

## 日常使用

- 打开红果短剧正常刷剧即可，什么都不用管
- 命中时右上角白点闪一下 = 已自动划走
- 无线调试被系统关闭时会发通知，点通知重连

## 调优

App 内「高级参数」全部可调、即改即生效（无需重编译）：

| 想要 | 改哪里 |
|---|---|
| **识别更快** | 高级参数 → 检测间隔 `300ms` 改成 `200ms`（更吃电一点） |
| 滑动更狠（默认 80%→10% 屏高） | 高级参数 → 滑动起点/终点 |
| 误滑了正常页面 | 关闭「像素检测」试试，或调高模板阈值 |
| 省电 | 什么都不用做：息屏自动停检（1.5s 低频保活），目标 App 不在前台自动降到 1s |

## 隐私与安全

- **不联网上传任何数据**：App 唯一的网络连接是本机回环上的无线调试端口
- ADB 密钥只存在本机应用私有目录，用于和手机自己的 adbd 握手
- 无障碍服务只读取前台窗口的文字与截图用于判定，不做任何点击/输入
- 本项目不修改红果客户端，不涉及其数据

## 常见问题

**Q: 突然不滑了？**
按顺序查：① Wi-Fi 连着没；② 无障碍开关是否还在（部分国产系统会自动关掉，重新打开即可）；③ App 日志页看最近动作；④ 无障碍开着但日志没动静 → 把无障碍关一下再开（通道僵死，App 看门狗一般会自动修复）。

**Q: 有广告没划走？**
把 App 日志页内容发到 [Issues](../../issues)，附一句当时的页面情况（直播/插屏/首页卡片）。

**Q: 换了手机？**
重新走一遍 3 步教程。配对跟设备走，不通用。

**Q: 费电吗？**
不费。检测只在目标 App 前台时全速运行（250ms 节奏）；息屏自动停检；不在目标 App 时降频到 1s。

## 自己构建

```bash
git clone https://github.com/jvkal/-hongguo-ad-swiper.git
cd -hongguo-ad-swiper
./gradlew assembleRelease
# 产物: app/build/outputs/apk/release/app-release.apk
```

要求：JDK 17+ 和 Android SDK（含 platform 34）。修改识别参数见 `Config.java`，核心判定见 `SkipService.performCheck()` / `analyze()`。
